# Online Food Ordering and Management System

## Project Description
The Online Food Ordering and Management System is a web-based application that allows customers to browse food items, view prices and descriptions, add food to a shopping cart, provide delivery details, and place food orders online. Restaurant staff can manage food items, prices, availability, and customer orders. The administrator can manage users, food categories, food items, orders, and basic system information.

## Problem Statement
Manual food ordering through phone calls, social media messages, or direct orders can cause incorrect orders, missing customer details, delays, and difficulty tracking order status. Customers may also have difficulty checking menus, prices, and food availability. This system provides a centralized platform for ordering and order management.

## Objectives
- Provide online food ordering.
- Allow customers to browse and search food items.
- Provide a shopping cart and order confirmation.
- Store delivery details.
- Allow customers to view order history and status.
- Allow staff to manage food items and orders.
- Allow administrators to manage users and system data.
- Reduce manual ordering errors.

## Main Features
- User registration and login
- Customer profile
- Food category and food item management
- Food search and filtering
- Shopping cart
- Online ordering
- Cash on Delivery
- Online payment option/payment record
- Order status management
- Order history
- Administrator management

1. Install Visual Studio with the required ASP.NET/.NET workload.
2. Install SQL Server and SQL Server Management Studio if required.
3. Clone this repository.
4. Open the solution/project in Visual Studio.
5. Create the database using the SQL scripts in `database/`.
6. Configure the local database connection without committing secrets.
7. Build and run the application.
